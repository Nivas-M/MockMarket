# Agent Rules & Guidelines

Please refer to the primary project rules defined in [GEMINI.md](./GEMINI.md).

All agents and tools operating in this repository must strictly adhere to the rules detailed in [GEMINI.md](./GEMINI.md):
1. **Never run the project**: The user runs the project, or it will already be running.
2. **Implementation plan required for every single request**: No matter how small, always create an implementation plan and wait for approval before modifying code.
3. **No autonomous terminal commands**: Never execute terminal commands without explicit user permission.
4. **Always update ARCHITECTURE.md after each implementation**: Keep system architecture documentation continuously up to date.
